# Анализ структуры Oriflame

Клиентское веб-приложение для самостоятельного анализа партнёрской структуры по информационному листку Excel.

**Принцип:** пользователь загружает файл → обработка только в браузере → анализ → очистка данных. Сервер, база данных и постоянное хранение отчёта отсутствуют.

## Возможности MVP

- загрузка `.xlsx` / `.xls` через File API;
- распознавание колонок по названиям (порядок колонок не фиксирован);
- проверка целостности и предупреждения;
- выбор собственного номера партнёра с подтверждением ФИО;
- поиск по номеру и ФИО;
- карточка партнёра, структура по спонсору, сводные метрики и графики;
- кнопка «Очистить данные».

## Приватность

- файл не отправляется на backend;
- данные отчёта не пишутся в `localStorage`, `sessionStorage`, IndexedDB, cookies, Cache Storage;
- поиск и выбранный партнёр не попадают в URL;
- в репозиторий нельзя добавлять реальные информационные листки.

## Публикация GitHub Pages

Репозиторий: [github.com/dolinsv/list](https://github.com/dolinsv/list).

1. В настройках Pages выберите источник **GitHub Actions**.
2. После push в `main` workflow соберёт и опубликует сайт.
3. `base` в `vite.config.ts` равен `/list/`.

`https://dolinsv.github.io/list/`
