# Спецификация формата информационного листка (MVP)

Основано на листе `ActivityReport` типового информационного листка Oriflame (персональная группа).

## Метаданные (до таблицы)

Обычно первые строки содержат:

- название организации;
- строку вида `Информационный Листок за каталог: N / YYYY...`;
- строку `Партнёр: <номер> <ФИО> [Партнёр]`;
- пустую строку.

Номер из метастроки используется только как **предложение** корня и требует подтверждения.

## Заголовки таблицы

Распознавание идёт по названиям, не по индексам колонок.

| Поле модели | Типичные заголовки |

| fileLevel | Ур |
| partnerNumber | Партнёр |
| fullName | Фамилия Имя |
| registrationCatalog | Кат. Присоед |
| phone | Телефон |
| email | Электронная почта |
| sponsorNumber | Спонсор |

| personalBB | ББ Личн |

| wellnessBB | ББ, Well. |

## Правила

- Спонсор и пригласивший — разные поля.
- `registrationCatalog` — каталог присоединения, не последний заказ.
- Колонка «Ур» сохраняется, но уровни анализа считаются от выбранного корня по спонсору.
- Номера партнёров хранятся строками.
- Пустые показатели → `null`, не `0`.
